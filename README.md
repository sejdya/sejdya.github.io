# SEJYDA Website Starter

A bilingual, responsive static website starter for Society for Equity, Justice and Youth Development Association.

## Files
- `index.html` — website content and page structure
- `assets/style.css` — responsive visual design
- `assets/script.js` — mobile navigation and Bangla/English language toggle

## Before publishing
1. Replace `[Add official office address]`, `[Add official phone number]`, and `[Add official email address]` in `index.html`.
2. Add only confirmed team members, official programs, real activities, photographs and contact details.
3. The organization registration status is currently shown as "Registration in Process". Update it only after official registration is completed.
4. The program areas are clearly described as proposed focus areas. Confirm them before presenting them as active projects.

## Publish with GitHub Pages (free)
1. Create a GitHub account at https://github.com/signup
2. Create a **public** repository named `sejyda-website` (or another available name).
3. Upload `index.html` and the `assets` folder to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. Wait for deployment. The site URL will usually be `https://YOUR-USERNAME.github.io/sejyda-website/`.

GitHub Pages on GitHub Free requires a public repository. The published website is public. Do not upload passwords, private member records, identity documents, confidential case data or other sensitive information.

## Important limitations
This is a static website. It does not include a secure admin dashboard, database, user login, or server-side contact form. For now, add an official email address and link a Google Form for membership/contact submissions if needed.
